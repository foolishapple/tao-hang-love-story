# Táo & Hằng — Love Story

A lightweight static anniversary album for **Táo & Hằng**, together since **14/01/2019**.

## Features

- Romantic, soft photo-album aesthetic
- Page-turn style transitions
- Keyboard navigation (`←` / `→`), buttons and mobile swipe
- Live relationship duration counter
- Responsive desktop/mobile layout
- Google Drive-hosted selected memories and video preview
- No backend and no build step

## Run locally

Open `index.html` directly, or run any static HTTP server in this folder.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The expected URL will follow GitHub Pages' normal project-site format once Pages is enabled.

## Media

The album currently references selected media from the shared Drive folder by file ID, keeping the GitHub repository lightweight. If the Drive sharing policy changes, the images/video may stop loading for public visitors. They can later be copied into `assets/` for a fully self-contained deployment.
